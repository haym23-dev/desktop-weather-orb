◆ init()

bool LcdDisplay::init ( )

Initialise the panel hardware (SPI bus + framebuffers + panel init).

Deliberately NOT done in the constructor: the constructor runs before Serial/PSRAM are up, so a failure there is invisible and a halt() would stop setup() from ever running. Call from setup(), after logPSRAM().

Returns
false if the panel could not be brought up (display left inert)
