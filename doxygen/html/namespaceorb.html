float turns,
float startAngle = 0.0f )
inlinenoexcept

Map an LED index to its position on a bottom-to-top helical strand.

The strip is wound once around the vertical axis: index 0 sits at the bottom pole and index count - 1 at the top pole. turns is how many full revolutions the strand makes over that span. All the sky effects are derived from the returned direction, so the winding handedness only changes which side of the orb a feature lands on, not whether it works.

Parameters
indexLED index, 0 .. count - 1 (0 = bottom)
countTotal LEDs on the strand
turnsFull revolutions from bottom to top
startAngleAzimuth (radians) of index 0 around the axis

Render one frame of the sunny-day simulation into pixels.

The scene is built purely from each LED's direction on the orb:

  1. a vertical sky gradient (pale near the base, deep blue overhead),
  2. a warm sun disk with a wide glow falloff around sunAzimuthDeg / sunElevationDeg,
  3. seamless drifting cloud cover sampled from 3D value noise on the direction, which then shades the sun and lightens the sky.
Parameters
pixelsFramebuffer to fill (count entries)
pointsPrecomputed LED geometry, parallel to pixels
countNumber of LEDs
paramsScene tuning
timeMsMilliseconds since boot; drives the cloud drift
