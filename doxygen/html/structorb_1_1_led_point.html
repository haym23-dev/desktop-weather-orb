Detailed Description

A single addressable LED's position on the orb.

Directions are unit vectors in a right-handed frame with +Z pointing up (from the base of the orb toward its top):

+Z = up, the "zenith" of the sky -Z = down, the base +X = the 0 rad azimuth reference

azimuth is how far the strand has wrapped around the vertical axis (it grows past 2*pi as the helix climbs), and altitude is a cheap 0..1 scalar for the vertical position (0 = bottom pole, 1 = top pole) used by the sky gradients.
