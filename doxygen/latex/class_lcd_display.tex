Initialise the panel hardware (SPI bus + framebuffers + panel init).

Deliberately NOT done in the constructor: the constructor runs before Serial/\+\+PSRAM are up, so a failure there is invisible and a halt() would stop \doxylink{main_8cpp_a4fc01d736fe50cf5b977f755b675f11d}{setup()} from ever running. Call from \doxylink{main_8cpp_a4fc01d736fe50cf5b977f755b675f11d}{setup()}, after log\+PSRAM().

\begin{DoxyReturn}{Returns}
false if the panel could not be brought up (display left inert)
