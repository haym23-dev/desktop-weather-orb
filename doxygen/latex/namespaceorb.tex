Map an LED index to its position on a bottom-\/to-\/top helical strand.

The strip is wound once around the vertical axis: index 0 sits at the bottom pole and index {\ttfamily count -\/ 1} at the top pole. {\ttfamily turns} is how many full revolutions the strand makes over that span. All the sky effects are derived from the returned direction, so the winding handedness only changes which side of the orb a feature lands on, not whether it works.

Render one frame of the sunny-\/day simulation into {\ttfamily pixels}.

The scene is built purely from each LED\textquotesingle{}s direction on the orb:
\begin{DoxyEnumerate}
\item a vertical sky gradient (pale near the base, deep blue overhead),
\item a warm sun disk with a wide glow falloff around {\ttfamily sun\+Azimuth\+Deg} / {\ttfamily sun\+Elevation\+Deg},
\item seamless drifting cloud cover sampled from 3D value noise on the direction, which then shades the sun and lightens the sky.
\end{DoxyEnumerate}
